# Home surface brief

- Scope: `app/page.tsx`, responsive marketing homepage.
- Visitor mode: Persuade.
- Audience and job: Charlotte event hosts comparing rental inventory and balloon styling, then requesting availability through one vendor.
- Primary action: Send Event Request. Supporting actions: Browse Rentals and Explore Balloon Decor.
- Required proof: combined 60/40 hero scene, exact published prices, complete category coverage, gallery/reel readiness, local contact details, and clear booking conditions.
- Direction: Garden soirée service book — cream and plum editorial fields, precise sans-serif operating detail, champagne rules, image-led asymmetric composition.
- Memorable moment: the first viewport visibly joins the tent, chairs, linen tables, cocktail tables, marquee number and balloon backdrop in one credible scene.
- Approved comp: `.impeccable/mocks/home-c.png`.
- Unresolved: real Pop Haus logo, photography, social URLs, videos, promo end date, and form backend.

## Implementation inventory

| Ingredient | Medium | Commitment |

| Reels | React media slots | 9:16 horizontal track; local MP4/external/Instagram-ready |
| Inquiry form | Semantic React form | Conditional delivery address and frontend-only success state |
